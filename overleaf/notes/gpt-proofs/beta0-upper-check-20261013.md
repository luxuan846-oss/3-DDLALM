# GPT Pro 核对结果：β=0 常数参数上界（2026-10-13）

任务说明见 `notes/prompts/gptpro-beta0-upper-check.md`。编号采用 Li26 v2 PDF（arXiv:2602.14185v2）。以下为 GPT Pro 返回内容的整理，推导原样保留。

## 结论

引用路线能支持 O(ε^{-3}) 上界，但要修订两处参数：

- 原始中心步长不能取与精度无关的常数。Li26 Condition 3.2(ii) 要求 α = Θ(1/(ℓ s))，所以 s = Θ(ε^{-1}) 时 α = Θ(ε)（单次运行内为常数）。α 与精度无关时能否达到同样上界，这条路线没有证明。
- s 的系数必须足够大：取 s = c_s/ε，c_s ≥ max{1, 16 L_h}。若 s = c/ε 且 c < c_1，充分小精度下仍落入下界区域。

修订后的命题：(ρ, γ, η, τ) 固定并满足步长条件，β = 0，s = c_s/ε，α = κ/(ℓ s)，则存在与精度、实例、维数无关的 C' 使
sup_{I∈I(C,Δ)} T^KKT_ε(θ, α, 0; I) ≤ C' ε^{-3}（充分小 ε）。

## 逐项推导

### 1. 算法对应
β=0、零初值给出 μ^k = 0。令 r := 1/γ，δ := 1/s，则
P_s(x, λ; z, 0) = D_ρ(x, λ) + (r/2)‖x − z‖² − (δ/2)‖λ‖²。
与 Li26 (3.1)、Algorithm 3 的对应：f_Li = D_ρ，y_Li = λ，r_x = r，r_y^t = δ，c^t = η，α_Li^t = τ，β_Li^t = α。原始步用旧乘子，对偶步用新原始变量，中心步用新原始变量，顺序一致。X = R^n 时原始投影恒等。

### 2. 乘子有界
∇_λ D_ρ(x^{k+1}, λ^k) = (q^k − λ^k)/ρ，故
λ^{k+1} = (1 − τ/ρ − τ/s) λ^k + (τ/ρ) q^k，‖q^k‖ ≤ L_h。
充分条件 τ ≤ ρs/(ρ+s)：两系数非负、和为 1 − τ/s ≤ 1，归纳得 ‖λ^k‖ ≤ L_h。
定义 ℓ := max{L_{D,x}, G_A, 1/ρ}，Y := {‖λ‖ ≤ 2 L_h}，D_Y := 4 L_h。Li26 条件含 τ ≤ 1/(11(ℓ + 1/s)) < 1/(1/ρ + 1/s)，故充分条件自动满足。L_h > 0 时乘子在 Y 内部，投影不触发，N_Y(λ^k) = {0}。（若 L_h 上界为零，分析中取任一正的 Lipschitz 上界即可，算法不变。）

### 3. 假设
Assumption 2.1 由项目的两个梯度估计直接满足；D_ρ(x, ·) 凹；Y 含零的紧凸集。D_ρ(x, λ) ≤ F(x)（在约化增广 Lagrangian 中取 y = A(x)）；取 q_x ∈ ∂h(A(x))，‖q_x‖ ≤ L_h，近端最优性给出 y(x, q_x) = A(x)、D_ρ(x, q_x) = F(x)，故 max_{λ∈Y} D_ρ(x, λ) = F(x)。Theorem 3.3 的证明只需势函数的统一下界；原始正则化子问题由强凸性取得最小值。初始间隙用的是扰动后的基准值，见第 5 项。

### 4. Condition 3.2 的翻译
记 a_s := r − ℓ − δ，b_s := ℓ + δ，需 a_s > 0。
- r = Θ(ℓ)，r > 3ℓ；
- η = Θ(1/ℓ)，0 < η < 1/(r + ℓ + δ)；
- τ = Θ(1/ℓ)，0 < τ ≤ min{ 1/(11 b_s), η² a_s² / (4 b_s (1 + η a_s)²) }；
- 0 < α ≤ min{ 1/36, a_s² / (384 r (r + ℓ + δ)²), 1/(384 r τ ω_s²) }，其中
  ω_s = (1/√δ) · (a_s + τ b_s (3r − 2 b_s)) / (τ a_s^{3/2})；
- α = Θ(δ/ℓ)。
固定其余参数时 ω_s² = Θ(s)，1/(384 r τ ω_s²) = Θ(1/s)，所以精度无关的 α 无法在 s → ∞ 时持续满足。
条件可同时满足的例子：γ = 1/(4ℓ)，η = 1/(12ℓ)，τ = 1/(800ℓ)，α = 1/(2,000,000 ℓ s)，并要求 s ≥ max{1, 1/ℓ}。此时 a_s ≥ 2ℓ，b_s ≤ 2ℓ，
η² a_s² / (4 b_s (1 + η a_s)²) ≥ 1/(392ℓ) > τ，a_s²/(384 r (r+ℓ+δ)²) ≥ 1/(13824ℓ)，ω_s² ≤ 800000 ℓ s，故 1/(384 r τ ω_s²) ≥ 1/(1536000 ℓ s) > α。Li26 条件蕴含 η < γ、τ < s，与算法族相容。

### 5. 初始间隙
Φ_s(x) := max_{λ∈Y} { D_ρ(x, λ) − ‖λ‖²/(2s) }。由对偶平滑恒等式，Φ_s(x) = D_{ρ+s}(x, 0)，最优乘子 λ = s q/(ρ+s)，范数 ≤ L_h，辅助域不改变最大值；且
F(x) − L_h²/(2(ρ+s)) ≤ Φ_s(x) ≤ F(x)。
记 G := G_f + G_A L_h，μ_γ := 1/γ − L_{D,x} > 0，v_0 := D_ρ(0,0)，d_0 := min_x{ D_ρ(x,0) + ‖x‖²/(2γ) }，p_0 := min_x{ Φ_s(x) + ‖x‖²/(2γ) }。则 d_0 ≥ v_0 − G²/(2μ_γ)，p_0 ≤ F(0)，v_0 ≥ F(0) − L_h²/(2ρ)。Li26 Def. 3.1(ii) 对应 Δ_Ψ2 = v_0 − 2 d_0 + 2 p_0 − inf Φ_s，故
Δ_Ψ2 ≤ Δ + L_h²/(2ρ) + G²/μ_γ + L_h²/(2(ρ+s)) ≤ Δ̄ := Δ + L_h²/ρ + G²/μ_γ。
Δ̄ 不依赖 s、精度、维数。

### 6. 度量换算
S_{k+1} := max{ ‖∇_x D_ρ(x^{k+1}, λ^{k+1})‖, ‖∇_λ D_ρ(x^{k+1}, λ^{k+1})‖ }（未扰动的 D_ρ，法锥项为零）。
d_k := λ^{k+1} − λ^k，‖d_k‖ ≤ τ( S_{k+1} + ‖d_k‖/ρ + L_h/s )，故 ‖d_k‖ ≤ τ/(1 − τ/ρ) · (S_{k+1} + L_h/s)。
R_k ≤ (1 + τℓ/(1 − τ/ρ)) S_{k+1} + τℓ/(1 − τ/ρ) · L_h/s。由 τℓ ≤ 1/11、τ/ρ ≤ 1/11：
R_k ≤ (11/10) S_{k+1} + L_h/(10 s)。
β=1 时的纯乘法换算不能原样用于这里。

### 7. 参数、下标与常数
取固定 κ > 0 使 α = κ/(ℓ s) 满足第 4 项（上例 κ = 1/2,000,000）。Li26 §4.2 的下降不等式与 (4.19)–(4.23) 经参数替换给出：存在 C_* = C_*(ηℓ, τℓ, 1/(γℓ), κ) > 0，使前 K 次更新中某 k 满足
S_{k+1} ≤ C_* ℓ √(s Δ̄ / K) + D_Y/s
（用 ℓ s ≥ 1 把 K^{-1/2} 项并入第一项）。取 c_s := max{1, 4 D_Y} = max{1, 16 L_h}，s = c_s/ε，则 D_Y/s ≤ ε/4。令 K = max{1, ⌈16 C_*² ℓ² c_s Δ̄ ε^{-3}⌉}，则某 0 ≤ k < K 有 S_{k+1} ≤ ε/2，且 R_k ≤ 11ε/20 + ε/160 = 89ε/160 < ε。故对充分小 ε ∈ (0, 1]，
T^KKT_ε ≤ C' ε^{-3}，C' := 1 + 16 C_*² ℓ² c_s Δ̄，
只依赖 (ρ, γ, η, τ, C, Δ)，不依赖 s(ε)。
下标：原文定理写 (x^t, y^t)，证明估计 (x^{t+1}, y^{t+1})，取 k = t 对应。原文尾段平均的显式常数需放宽一个固定因子；这里直接对前 K 次更新平均，与项目的最小残差定义一致。
**注意（Claude 标注）**：C_* 的存在性与依赖关系是 GPT Pro 按 Li26 §4.2 换算得到的，Li26 原文的 (4.19)–(4.23) 未逐行复核。

### 8. 与下界相容
ε(ρ+s) = ερ + c_s ≥ 1，而下界要求 ε(ρ+s) ≤ c_1 ≤ 1/224，无交集。Huber 分支：q_h a_0 = 4ε(ρ + 3s + 1) = 12 c_s + 4ε(ρ+1) ≥ 12，不满足所需的 q_h a_0 ≤ 1/4。
限定：上界使用充分大的 s 系数；单写 s = Θ(1/ε) 不够。

## 可用于附录的修订后证明（GPT Pro 原稿，记号同上）

**命题.** ℓ = max{L_f + L_A L_h + ρ G_A², G_A, 1/ρ}。固定 ρ, γ, η, τ, κ > 0，使 Li26 Condition 3.2 在对应 (r_x, r_y, c, α_Li, β_Li) = (1/γ, 1/s, η, τ, κ/(ℓ s)) 下对所有充分大的 s 成立。取 c_s = max{1, 16 L_h}，s = c_s/ε，α = κ/(ℓ s)，β = 0。则存在与精度、实例、维数无关的 C' > 0，使充分小精度下 sup_I T^KKT_ε(θ, α, 0; I) ≤ C' ε^{-3}。

**证明.** (a) μ^k = 0；取 Y = {‖λ‖ ≤ 2 L_h}；λ^{k+1} = (1 − τ/ρ − τ/s) λ^k + (τ/ρ) q^k，‖q^k‖ ≤ L_h，由步长条件归纳 ‖λ^k‖ ≤ L_h，投影不触发，SPLALM 与作用于 D_ρ 的 Li26 Algorithm 3 一致。(b) D_ρ 满足 Assumptions 2.1–2.2，max_{λ∈Y} D_ρ = F；Φ_s = D_{ρ+s}(·, 0)，inf Φ_s ≥ inf F − L_h²/(2(ρ+s))。(c) 初始间隙 Δ_Ψ2 ≤ Δ + L_h²/(2ρ) + G²/μ_γ + L_h²/(2(ρ+s))，对全类与所有精度一致有界。(d) 由 Li26 Thm 3.3(i) 及 §4.2 的估计，K = O(ε^{-3}) 次更新内存在 0 ≤ k < K 使 S_{k+1} ≤ ε/2，隐含常数只依赖固定参数与类常数。(e) R_k ≤ (11/10) S_{k+1} + L_h/(10 s)；c_s ≥ 16 L_h 给出 R_k ≤ 11ε/20 + ε/160 < ε。证毕。
