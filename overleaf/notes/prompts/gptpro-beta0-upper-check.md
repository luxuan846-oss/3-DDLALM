### 一、需要核对的命题

在我们的算法族中取对偶中心步长 β=0（因此 μ^k≡0），ρ 固定，s=Θ(1/ε)，原始中心步长 α 取只依赖类常数的常数。命题：存在只依赖 θ、C、Δ 的常数 C'，使对问题类 I(C,Δ) 中的所有实例，

T^KKT_ε(θ, α, 0; I) ≤ C' ε^{-3}。

计划的论证：β=0 时 SPLALM 恰好是 Li et al. (2026) 的 Perturbed Smoothed GDA（Algorithm 3）作用在 D_ρ 上，于是引用其 Theorem 3.3(i)，再把初始间隙与驻点度量换算成我们的量。

### 二、可用材料

**我们论文的定义**（记号以此为准）：

- 问题：min_x F(x) := f(x) + h(A(x))。问题类 I(C,Δ)，C=(L_f,G_f,L_A,G_A,L_h)：‖∇f(x)−∇f(x')‖≤L_f‖x−x'‖，‖∇f‖≤G_f，‖J_A(x)−J_A(x')‖≤L_A‖x−x'‖，‖J_A‖≤G_A；h 凸且 L_h-Lipschitz；F(0)−inf F ≤ Δ。维数任意。
- 约化增广 Lagrangian：D_ρ(x,λ) := min_y { f(x)+h(y)+⟨λ, A(x)−y⟩+(ρ/2)‖A(x)−y‖² }，y(x,λ) := prox_{h/ρ}(A(x)+λ/ρ)，q(x,λ) := λ+ρ[A(x)−y(x,λ)] ∈ ∂h(y(x,λ))。恒等式：∇_x D_ρ = ∇f + J_A^T q，∇_λ D_ρ = A(x) − y(x,λ)。
- 势函数：P_s(x,λ;z,μ) := D_ρ(x,λ) + (1/(2γ))‖x−z‖² − (1/(2s))‖λ−μ‖²。
- SPLALM（参数 θ=(ρ,s,γ,η,τ)，ρ>0，0<η≤γ，0<τ≤s；中心步长 (α,β)∈[0,1]²），从 (x^0,λ^0,z^0,μ^0)=0 出发：
  x^{k+1} = x^k − η ∇_x P_s(x^k,λ^k;z^k,μ^k)，
  λ^{k+1} = λ^k + τ ∇_λ P_s(x^{k+1},λ^k;z^k,μ^k)，
  z^{k+1} = z^k + α(x^{k+1}−z^k)，μ^{k+1} = μ^k + β(λ^{k+1}−μ^k)。
  第 k 步输出 (x^{k+1}, y^{k+1}, q^k) := (x^{k+1}, y(x^{k+1},λ^k), q(x^{k+1},λ^k))。
- KKT 残差：R_KKT(x,y,q) := max{ ‖∇f(x)+J_A(x)^T q‖, ‖A(x)−y‖ }；R_k := R_KKT(x^{k+1},y^{k+1},q^k) = max{ ‖∇_x D_ρ(x^{k+1},λ^k)‖, ‖∇_λ D_ρ(x^{k+1},λ^k)‖ }。
- 复杂度：T^KKT_ε(θ,α,β;I) := inf{K≥1 : min_{0≤k<K} R_k ≤ ε}；族复杂度为 inf_{(α,β)} sup_{I∈I(C,Δ)} T^KKT_ε。(α,β) 可依赖 ε、θ、(C,Δ)，不可依赖实例。
- 光滑性（论文 Proposition 6.1 的 D_ρ 部分）：L_{D,x} := L_f + L_A L_h + ρG_A²，μ_γ := 1/γ − L_{D,x}；‖∇_x D_ρ(x,λ)−∇_x D_ρ(x',λ')‖ ≤ L_{D,x}‖x−x'‖ + G_A‖λ−λ'‖，‖∇_λ D_ρ(x,λ)−∇_λ D_ρ(x',λ')‖ ≤ G_A‖x−x'‖ + (1/ρ)‖λ−λ'‖。
- 对偶平滑恒等式：D_σ(x,λ) = max_q { f(x)+⟨A(x),q⟩−h*(q) − ‖q−λ‖²/(2σ) }。
- 已有下界（论文 Theorem 3.2）：存在 c_1=c_1(γ,η,τ) ≤ 1/224，使 ε(ρ+s) ≤ c_1 时，对所有常数 (α,β) 复杂度为 Ω(ε^{-4})。其中 β=0 分支用一维 Huber 实例（外函数二次分支曲率 q_h=2s+1，A 为常数 a_0=4ε(ρ+3s+1)/(2s+1)，关键条件 q_h a_0 = 4ε(ρ+3s+1) ≤ 1/4），可行性残差恒大于 2ε。

**已完成的平行核对（β=1，可作参照，不必重做）**：β=1 时 SPLALM 即 Smoothed GDA 作用在 D_ρ 上。已核对：取对偶域 Y := {‖λ‖≤2L_h}（直径 D_Y=4L_h），ℓ := max{L_{D,x}, G_A, 1/ρ} 满足 [Li26] Assumption 2.1；max_{λ∈Y} D_ρ(x,λ)=F(x)；Δ_Ψ2 ≤ Δ + L_h²/(2ρ) + (G_f+G_A L_h)²/μ_γ；R_k ≤ (11/10)·S_{k+1}，其中 S_{k+1} 为 [Li26] 在 (x^{k+1},λ^{k+1}) 处的 GS 量；乘子 ‖λ^k‖≤L_h 使投影不触发。

### 三、逐项核对清单

对每一项给出：结论（成立 / 不成立 / 需补条件）、推导、所用 [Li26] 的编号。

1. **算法对应。** β=0 时 μ^k≡0。验证 SPLALM 的四步更新与 [Li26] Algorithm 3 在替换 f→D_ρ、y→λ、r_x→1/γ、r_y^t→1/s、c^t→η、α^t→τ、β^t→α 下逐步一致（含更新顺序与 z 的更新）。
2. **乘子有界与投影不触发。** 验证 λ^{k+1} = (1−τ/ρ−τ/s)λ^k + (τ/ρ)q^k，并由 ‖q^k‖≤L_h 推出从零出发 ‖λ^k‖≤L_h（列出所需的 τ 条件）。由此 [Li26] 的投影 proj_Y 不触发，GS 定义中的法锥项为零。
3. **假设。** 验证 D_ρ 在 R^n×Y 上满足 Assumption 2.1（ℓ 同上）与 Assumption 2.2；验证 max_{λ∈Y} D_ρ(x,λ)=F(x)，从而 [Li26] 中 min_x max_{y∈Y} f 等于 inf F。[Li26] 写 min，我们的类只保证 inf F>−∞：判断这是否影响 Theorem 3.3 的证明，若影响，指出证明中用到最小值点存在的位置。
4. **Condition 3.2(ii) 的翻译。** 把 Condition 3.2 的全部不等式（含 ω^t 的定义与 β^t ≤ 1/(384 r_x α^t (ω^t)²)、β^t=Θ(r_y^t/ℓ)）写成我们的参数。特别核对：r_y = 1/s = Θ(ε/D_Y) 时这些条件能否同时满足；α（即 [Li26] 的 β^t）的尺度是否为 Θ(ε)，其常数只依赖哪些量；我们的定义要求 τ≤s、η≤γ，是否与之相容。若条件可化简为少数几条充分条件，给出化简及推导。
5. **初始间隙。** Definition 3.1(ii) 在 r_y>0 时 F_0 含 −(r_y/2)‖y‖²。在零初值 (x^0,λ^0,z^0)=0 下，给出 Δ_Ψ2 关于 (Δ, C, θ, s) 的显式上界，并说明它对整个问题类一致，且在 s=Θ(1/ε) 时不随 ε 发散。
6. **驻点度量换算。** Theorem 3.3(i) 保证 (x^t,y^t) 是原问题（未扰动的 f=D_ρ）的 ε-GS，度量点为更新后的 (x^{k+1},λ^{k+1})。我们的 R_k 在 (x^{k+1},λ^k) 处计算。给出 R_k 关于 S_{k+1} 的显式上界；注意 β=0 时 λ^{k+1}−λ^k = τ[∇_λ D_ρ(x^{k+1},λ^k) − λ^k/s] 多出的一项，并说明它在 s=Θ(1/ε) 下为 O(ε)。
7. **下标与一致性。** 验证 Theorem 3.3(i) 的"存在 t ≤ O(·)"对应 T^KKT_ε ≤ C'ε^{-3}；验证 α、s 的取法只依赖 (ε, θ 中其余参数, C, Δ)，不依赖实例；写出 C' 依赖哪些量（ηℓ、τℓ、γℓ 等）。
