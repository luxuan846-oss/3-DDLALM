# B2′ 的 $O(\epsilon^{-5/2})$ 上界：汇总（2026-11-09）

推导：Opus 5.5（effort xhigh）。审查：gpt-6-astra（x1api，reasoning effort high）。四关全部通过审查，全程为解析推导，没有数值实验。

## 结论

**固定 $\rho$ 时，SPLALM（$\beta=0$）只需在对偶步加一个 Nesterov 外推，就能达到 $O(\epsilon^{-5/2})$ 迭代复杂度，不需要投影，也不需要 OGDA 或 extragradient。** 这个算法记为 B2′。B2′ 不在 $\mathcal C_\theta$ 中，所以与族内 $\Omega(\epsilon^{-3})$ 下界不冲突；两者合起来，构成固定 $\rho$ 下的分离结果。

## 算法 B2′

从零初值出发，$\boldsymbol\lambda^{-1}=\boldsymbol\lambda^0$，对 $k\ge0$：

$$
\bar{\boldsymbol\lambda}^k=\boldsymbol\lambda^k+\theta_{\mathrm m}(\boldsymbol\lambda^k-\boldsymbol\lambda^{k-1}),\qquad
\mathbf x^{k+1}=\mathbf x^k-\gamma\nabla_{\mathbf x}\mathcal P_s(\mathbf x^k,\bar{\boldsymbol\lambda}^k;\mathbf z^k,\mathbf 0),
$$

$$
\boldsymbol\lambda^{k+1}=\bar{\boldsymbol\lambda}^k+\tau\nabla_{\boldsymbol\lambda}\mathcal P_s(\mathbf x^{k+1},\bar{\boldsymbol\lambda}^k;\mathbf z^k,\mathbf 0),\qquad
\mathbf z^{k+1}=\mathbf z^k+\alpha(\mathbf x^{k+1}-\mathbf z^k).
$$

输出取 $(\mathbf x^{k+1},\mathbf y(\mathbf x^{k+1},\bar{\boldsymbol\lambda}^k),\mathbf q(\mathbf x^{k+1},\bar{\boldsymbol\lambda}^k))$。oracle 代价与 SPLALM 相同：$K$ 步共 $3K+1$ 次调用。

**参数，即假设 (H)**：
- $\gamma L_{\mathcal D,\mathbf x}\le1/10$，$\eta=\gamma$；
- $\tau\le\min\{\rho/4,1/(14\gamma G_{\mathcal A}^2)\}$；
- $s=c_s/\epsilon$，其中 $c_s\ge2\bar C_\lambda L_h$；
- 记 $\varsigma=\sqrt{\tau/s}$，取 $\theta_{\mathrm m}=(1-\varsigma)/(1+\varsigma)$，$\alpha=c_\alpha\varsigma$，$c_\alpha\le1/6$。

**复杂度**：当 $K\ge4C_R^2\Delta_{\mathcal W}\sqrt{c_s/\tau}\,\epsilon^{-5/2}$ 时，前 $K$ 个输出中有一个满足 $\mathcal R_{\mathrm{KKT}}\le\epsilon$。其中 $\Delta_{\mathcal W}=\Delta+L_h^2/\rho+(G_f+G_{\mathcal A}L_h)^2/(2\mu_\gamma)$，与 $s$ 无关。

## 查新（2026-11-09，Web 检索加本地全文）

结论：没有找到与 B2′ 完全相同的工作，即"非凸 ALM、固定 $\rho$、单循环、对偶 Nesterov 外推、$\epsilon^{-5/2}$"这一组合。最接近的两篇如下。

- **Pan–Zheng–Li, Tracked-FOAM**（arXiv:2609.14235；本地全文 `memory/literature/complexity_2026-09_to_2026-10-03/raw/2609.14235v1.txt`）。问题是光滑 NC-C、对偶域紧。方法是中心每移动一次，就用 warm start 跑 $K_\rho=O(\sqrt{\ell/r_y})$ 步加速 SC-SC 求解器 FOAM（Kovalev–Gasnikov 2022），每次只要求 Lyapunov 函数缩小常数倍（1/400）。全局势函数为 $W^t=p_r(\mathbf z^t)+2B^t$，GS 复杂度为 $O(\epsilon^{-5/2})$，OS 复杂度为 $O(\epsilon^{-3})$ 且最优。**它的证明结构与我们的 G3（$\mathcal W_k=p_s(\mathbf z^k)+\tfrac12E_k$）相同**，区别有三点：
  - 它是内外两层循环，每 $\sqrt s$ 步移动一次中心；B2′ 每步都移动中心，步长 $\alpha\sim\varsigma$。
  - FOAM 对两块都做加速，维护快慢两对迭代，需要 relative-prox 和投影；B2′ 只对对偶块做 Nesterov 外推，原始块做一步梯度，不需要投影。
  - 它的问题类是光滑 NC-C 加紧对偶域；B2′ 是 ALM 形式，乘子无界。
- **Zhang–Xu**（arXiv:2609.17973）：单循环，heavy-ball 型对偶动量加 EG，需要投影。
- **其他，均不重合**：
  - 凸情形对乘子做 Nesterov 外推（He–Yuan 2010；Xu 2017，arXiv:1711.05812，双循环；对偶加速 ADMM，arXiv:2310.16404）；
  - 非凸惯性 ADMM 只对原始变量做外推（Comput. Optim. Appl. 2022；arXiv:2212.11336）；
  - MLALM（Shi–Wang–Wang，MOR）的动量作用在随机梯度估计上；
  - Melo 等的加速不精确近端 ALM 是 $\epsilon^{-5/2}$，但它是内层加速、多层循环。

**对新意的判断（推断）：** B2′ 的证明骨架，即"包络函数 + 内层加速能量，内层只需常数倍收缩"，已经出现在 Tracked-FOAM 中。B2′ 新增的是三件事：
1. 单循环，每步移动一次中心；
2. 内层只用对偶 Nesterov 外推加交替 GDA，这需要 G2 的部分模型技巧；
3. ALM 形式下的无投影有界性（G1）。

审稿人可能会说"B2′ 就是 Tracked-FOAM 取 $K=1$，再把 FOAM 换成更简单的求解器"。论文里需要正面回应：$K=1$ 时，内层能量只按 $\varsigma$ 收缩，不再是常数倍，这正是 G3 中 (F1)、(F2) 处理的问题。

## 待证与边界

- 含 OGDA 修正的 B2 是否加速：待证。本证明路线对 B2 不能闭合，这只是路线层面的结论。
- anytime 版本，即 $s_k\sim k^{2/5}$：待证。G1 要求 $\theta_{\mathrm m}$ 为常数，时变时滤波器也随时间变化。
- $\alpha\gg\varsigma$ 时 B2′ 是否失效：待证。
- 真实轨迹的乘子半径阶：待证。只影响常数。
