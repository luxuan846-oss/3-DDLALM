# A Fixed-Penalty Linearized Augmented Lagrangian Method with Classical Multiplier Updates

## Outline

- 论文研究带非线性等式约束的光滑非凸优化。
- 核心算法用一次线性化增广拉格朗日步替代非线性 primal subproblem，同时保留 classical multiplier update。
- 分析的技术中心是控制线性化模型与非线性乘子更新之间的二阶误差。
- 主要结果包括确定性复杂度、随机复杂度、轨迹局部化、KL 全序列收敛和二阶修正。

## Conclusion

**论文的核心贡献是：在固定且与目标精度无关的 penalty 参数下，用一次 SPD 线性系统求解完成 primal update，并在 classical nonlinear-residual multiplier update 下证明确定性 \(\mathcal O(\varepsilon^{-2})\) 复杂度。**

该结论的适用范围受到 uniform LICQ、参数可行性条件、近可行初始化和 regularity-region buffer 的约束。随机无条件结果还依赖已知梯度上界、exact membership test 与 safeguarded restart。论文证明链在初步核查下闭合；主要问题位于常数、初始化、局部化和线性系统真实成本，不在 \(\varepsilon\) 指数的代数推导。

## 1. 研究问题

论文考虑

\[
\min_{x\in\mathbb R^n} f(x)
\quad\text{subject to}\quad
c(x)=0,
\]

其中 \(f\) 可非凸，\(c\) 可非线性；随机情形为 \(f(x)=\mathbb E[F(x;\xi)]\)，约束保持确定性。

传统 ALM 需要近似求解非线性 augmented-Lagrangian subproblem。论文要回答的问题是：**能否仅求解一个线性系统，保留 classical multiplier update，并使用固定 penalty 获得可证明的复杂度？**

## 2. NR-LALM 算法

给定固定 \(\rho,\beta>0\)，算法求解

\[
\bigl(\beta I_n+\rho\nabla c(x_k)\nabla c(x_k)^\top\bigr)p_k
=-
\nabla f(x_k)-\nabla c(x_k)\bigl(\lambda_k+\rho c(x_k)\bigr),
\]

然后更新

\[
x_{k+1}=x_k+p_k,
\qquad
\lambda_{k+1}=\lambda_k+\rho c(x_{k+1}).
\]

系数矩阵为 SPD。每步需要一次 objective gradient、一次 constraint Jacobian、一次新 constraint residual 和一次 SPD solve。

## 3. 核心技术机制

primal model 使用线性化约束，multiplier update 使用真实非线性残差。定义

\[
d_k=c(x_{k+1})-c(x_k)-\nabla c(x_k)^\top p_k.
\]

模型一阶条件与 multiplier update 给出

\[
\nabla f(x_k)+\nabla c(x_k)\lambda_{k+1}+\beta p_k
=\rho\nabla c(x_k)d_k.
\]

若 \(\nabla c\) 为 \(L_c\)-Lipschitz，则

\[
\|d_k\|\le \frac{L_c}{2}\|p_k\|^2.
\]

论文通过参数条件先证明 \(\|p_k\|\le\Delta\) 和 \(\|\lambda_k\|\le\Lambda\)，再建立 primal decrease 与 two-step multiplier-increment bound。Lyapunov 函数为

\[
\Phi_k
=\mathcal L_\rho(x_k,\lambda_k)
+\frac{C_{\lambda,p}}{\rho}\|p_{k-1}\|^2,
\]

并满足

\[
\Phi_{k+1}
\le
\Phi_k-\frac{\beta}{4}\|p_k\|^2.
\]

KKT residual 随后由两步 primal energy 控制：

\[
\mathcal R_{k+1}^2
\le
C_R\bigl(\|p_k\|^2+\|p_{k-1}\|^2\bigr).
\]

求和后得到 \(\min_k\mathcal R_{k+1}^2=\mathcal O(K^{-1})\)。

## 4. 主要结果

### 4.1 确定性结果

Theorem 2.12 证明

\[
\min_{1\le k\le K-1}\mathcal R_{k+1}^2
\le
\frac{C_{\mathrm{det}}}{K-1}.
\]

因此 \(K=\mathcal O(\varepsilon^{-2})\) 时可获得 \(\varepsilon\)-KKT pair。对应复杂度为：

- \(\mathcal O(\varepsilon^{-2})\) iterations；
- \(\mathcal O(\varepsilon^{-2})\) first-order oracle evaluations；
- \(\mathcal O(\varepsilon^{-2})\) exact Jacobian-induced linear-system solves。

### 4.2 随机结果

论文使用 projected SPIDER。取

\[
B=K,
\qquad
Q=\lceil\sqrt K\rceil,
\qquad
b=\Theta(\sqrt K),
\]

可得到 expected squared KKT residual 为 \(\mathcal O(K^{-1})\)。当 \(K=\mathcal O(\varepsilon^{-2})\) 时：

- stochastic-gradient complexity 为 \(\mathcal O(\varepsilon^{-3})\)；
- constraint/Jacobian evaluations 与 exact solves 为 \(\mathcal O(\varepsilon^{-2})\)。

局部正则情形通过 stopped process 控制 exit probability，再用 safeguarded restart 获得无条件期望保证。

### 4.3 全序列收敛

在 deterministic localization set 紧致，且 lifted energy 满足 Kurdyka-Lojasiewicz property 时，Theorem 2.13 证明 primal-dual trajectory 有限长度，整个序列收敛到 KKT pair。

### 4.4 二阶修正

NR-LALM+SOC 在 \(z_k=x_k+p_k\) 处计算 minimum-norm correction \(q_k\)，将 constraint-linearization error 从

\[
\mathcal O(\|p_k\|^2)
\]

降低到

\[
\mathcal O(\|p_k\|^4).
\]

复杂度指数保持不变，但每步增加一次约束与 Jacobian 评估及一个 \(m\times m\) correction solve。论文证明 SOC 的充分参数域包含 base method 的充分参数域，并给出严格包含的标量例子。

## 5. 关键假设与真实边界

1. **Uniform LICQ**：\(\|\nabla c(x)u\|\ge\sigma\|u\|\)。当 \(\sigma\) 较小时，penalty 下界与复杂度常数迅速增大。
2. **梯度和 Jacobian 局部有界且 Lipschitz**：误差控制与 multiplier bound 均依赖这些常数。
3. **固定参数满足显式充分条件**：论文证明这些条件存在可行解，但它们不是实用的 parameter-selection rule。
4. **初始化要求**：\(\|\lambda_0\|\le\Lambda\) 且 \(\rho\|c(x_0)\|\le\Lambda\)。寻找近可行初值的成本未计入复杂度。
5. **Localization buffer**：局部正则情形要求参数相关 level set 的整个邻域包含在 \(\mathcal U\) 中。
6. **Exact solve accounting**：论文计算 solve 次数，不计算 SPD 系统的算术成本、条件数依赖或 Krylov 迭代数。
7. **随机额外条件**：算法需要已知梯度上界 \(G\)；restart 需要 exact localization-set membership test 和独立新样本。

## 6. 初步审计判断

**已确认事实**：确定性和随机复杂度的代数链闭合，未发现推翻主定理的错误。Lean 4 仓库给出了正文 24 个对象的映射，并声明无 `sorry`、`admit` 和 project-defined `axiom`；本轮尚未完成本地全量复编译。

**明确松界**：Lemma 2.8 从

\[
\sigma\|\lambda_{k+1}-\lambda_k\|
\le
A_p\|p_k\|+B_p\|p_{k-1}\|
\]

定义

\[
C_{\lambda,p}
=\frac{4}{\sigma^2}\max\{A_p^2,B_p^2\}.
\]

Cauchy-Schwarz 直接给出更紧的

\[
C_{\lambda,p}^{\mathrm{tight}}
=\frac{A_p^2+B_p^2}{\sigma^2}.
\]

该紧化会扩大充分参数域并改善 penalty 下界与复杂度常数，但不改变 \(\varepsilon\) 指数。

## 7. 数值实验

- 机制实验验证 base error 的 log-log slope 约为 \(2.001\)，SOC error 约为 \(4.022\)。
- 15 个高维 LIBSVM 问题比较 NR-LALM、NR-LALM+SOC、L-AL 与 IPOPT。两种新方法在 13 个数据集上取得最低 median first-hit time，NR-LALM+SOC 在其中 12 个最快。
- 随机实验在 covtype 与 MNIST 上使用匹配的 stochastic-gradient budget，比较 MLALM 与 S-SQP；指标为对 multiplier 最小化后的 primal-point residual，因此没有评价各方法返回 multiplier 的质量。

## 8. 总体评价

**论文的理论主线清晰，贡献集中在 quadratic perturbation 的可控性与由此得到的固定 penalty 复杂度。** 与现有项目最相关的内容是 multiplier-increment estimate、trajectory localization、fixed-parameter feasibility 以及 SOC 对约束线性化误差的高阶抑制。

需要保持谨慎的部分是：定理条件距离直接可实现的全局算法仍有差距。论文自身将 inequalities、inexact solves、adaptive parameters 与 globalization 列为开放问题。

**精华总结：NR-LALM 用一次 SPD 线性系统和 classical multiplier update 达到确定性 \(\mathcal O(\varepsilon^{-2})\)；理论指数可信，主要研究空间位于常数紧化、inexact solve、弱化 LICQ、去除近可行初始化与实现 globalization。**
